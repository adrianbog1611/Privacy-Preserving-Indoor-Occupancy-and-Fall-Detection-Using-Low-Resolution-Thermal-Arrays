# Privacy-Preserving-Indoor-Occupancy-and-Fall-Detection-Using-Low-Resolution-Thermal-Arrays

This project proposes a non-intrusive smart home monitoring system based on an STM32 microcontroller and a low-resolution thermal array sensor. By executing local edge-computing algorithms such as bilinear interpolation, background subtraction, and spatial clustering, the system accurately detects human presence, counts occupants, and identifies potential falls. No high-resolution images are captured, ensuring strict user privacy while transmitting only anonymized status flags to an IoT dashboard.
